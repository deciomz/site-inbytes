dos dados dos alunos

Os pais preenchem. A escola recebe tudo organizado.

Está a começar o ano lectivo?Facilite as inscrições e a actualização dos dados das crianças.

COMO FUNCIONA?

  1. 1

    Os pais preenchem os dados
    por celular ou computador

    Pela internet, os pais podem inscrever os filhos ou actualizar os seus dados e enviar as fotografias.

  2. 2

    Imprimem, assinam e entregam

    No final, é gerada uma ficha para imprimir, assinar e entregar na escola.

  3. 3

    A escola recebe os dados todas as semanas

    A inbytes entrega os dados preenchidos, incluindo as fotografias, num ficheiro Excel.
